# PMK — Infinite Research Portfolio

A responsive, single-page portfolio website combining a moonlit architectural environment with a research-terminal visual language.

## Run locally

1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. For best results, serve the folder with a local static server (for example, VS Code Live Server).

## Included

- Responsive portfolio website (`index.html`, `styles.css`, `script.js`)
- Light and dark theme toggle with saved preference and soft neumorphic surfaces across the hero and content sections
- Generated visual environment (`assets/infinite-room.png`)
- Click-to-view certificate gallery (`assets/certificates/`)
- Project showcase with live apps, GitHub repositories, and expandable case studies for Noor-ul-Quran, Smart Library Demand Predictor, AirSight, and the 3D Personal Portfolio
- AirSight's case study distinguishes its generated sample-data frontend MVP from live air-quality ingestion or a trained forecasting model
- In-page one-page resume with browser print and save-as-PDF support
- Working section navigation, project repository/live-app links, LinkedIn/GitHub links, and a Gmail compose link in the header, contact section, and resume

## Customize

Edit `index.html` for text and links. Edit `styles.css` for visual styling. Replace `assets/infinite-room.png` to change the hero environment.

The project is static and does not require a build step or package installation.
